# 개발 인계

README의 실행 명령으로 개발 미리보기를 엽니다. 실제 시범은 B00~B09 초안과 연속 이동 시험이 포함됩니다.

태극 1장은 전사표와 검수된 연속 모션부터 이어갑니다. 먼저 공식 시범의 각 구간을 `taegeuk-01-review.csv`에 연결하고, 본·축·길이·해시가 일치하는 자산을 검수 화면에 연결합니다. 공개 항목은 검수 근거와 실제 검수자의 확인이 있는 버전만 `release-manifest.json`에 추가합니다. URL은 `/assets/` 아래의 해당 GLB와 시간 표본 파일을 사용합니다.

공개용 빌드의 QA 파일 제외를 검사합니다. 빌드의 릴리스 간 되돌리기는 동일한 manifest와 해시 자산을 포함한 직전 ZIP을 다시 사용합니다. 학습 진도는 별도 IndexedDB에 유지됩니다.
