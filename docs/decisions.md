# 구현 결정

- 새 저장소에 React·TypeScript·Vite·Three.js·R3F를 구성했습니다.
- 기술 재생은 절대 시간 샘플링을 사용합니다. 블렌더가 베이크한 MotionRoot만 이동을 소유합니다.
- 리그는 +Z 초기 정면, -X 해부학적 오른쪽, +X 왼쪽입니다. 카메라 변경은 신체 좌우에 영향을 주지 않습니다.
- 표준 품새선 검수가 완료될 때까지 개발용 이동 경로는 실제 root 표본을 표시합니다.
- 브라우저 검수 환경의 WebGL 제한에 대응해 Canvas 호환 3D 경로를 추가했습니다.
- 승인 기록은 실제 검수자, 시각, 근거, 버전과 해시를 함께 요구합니다.
- 별도 운영 배포 지시가 없으므로 설계 P14의 로컬 실행·인계 절차를 적용했습니다.
