# 검증 기록

## 소스·시간·자산

- `npm run typecheck`, `npm run lint`, `npm run content:validate`, `npm run assets:validate` 통과.
- `npm run test:unit` 7건 통과. 4개 배속, 끝 프레임, 20회 반복, 멈춤 후 복귀, 검수 게이트, 음성 큐 재탐색, 실제 GLB 100회 순서 교차 탐색을 확인했습니다.
- GLB 2.0 한 파일에 21개 애니메이션, 스킨 1개, 25,064개 삼각형을 확인했습니다. 리그 이름·모션 길이·해시가 일치합니다.
- `npm run release:check` 종료 코드 2. 지도자 승인된 B00~B09와 태극 1장 시범을 확보하면 다시 검사합니다.

## 브라우저

Chrome의 현재 검수 환경에서 WebGL 컨텍스트가 생성되지 않아, 같은 GLB를 읽는 호환 3D 경로에서 검사했습니다.

- 앞차기 뻗기 1.98초로 이동, 왼쪽 시점 전환, 마지막 4.8초에서 연결 단계 표시.
- 회수 단계, 2D 포즈 전환, 3D 복귀, 확인 문제 정답 저장, 복습에서 2.889초로 복원.
- 품새 카탈로그 17종, 태극 1장 공식 원문 링크와 검수 대기 상태, 이동·연결 테스트의 구간 모드와 이동 지도.
- 연속 모션을 실제 재생·일시정지하고 1.006초에 멈춘 것을 확인. 수업 모드 진입 시 1.98초 유지.
- 반응형 시험 화면 360×800, 390×844, 844×390, 1024×768, 1366×768, 1920×1080. 각 화면에서 가로 넘침 0, 재생 버튼 가로 범위 안에 표시.

## 남은 검증

실제 WebGL 기기, 실제 모바일 GPU 성능, 음성 시스템의 설치 언어별 동작, 태권도 지도자의 전체 동작 검수는 별도 확인 대상입니다. 합격·승급 판단 수치는 제공하지 않습니다.

## 빌드

공개·개발 빌드를 모두 생성했습니다. 개발 빌드 전체 파일은 5,020,255바이트입니다. 공개 빌드에서 GLB·동작 트랙·개발용 수업 데이터 번들을 제외한 것을 검사했습니다.
